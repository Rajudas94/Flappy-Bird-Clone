# Flappy Bird Clone

A clone of the popular Flappy Bird game, developed using Python and Pygame.

Features:
- Physics-based bird movement – Realistic gravity and flapping mechanics.<br>
- Obstacle generation – Randomly positioned pipes to navigate through.<br>
- Score tracking – Keeps track of the player's progress.<br>

Installation:<br>
- Clone the repository:
git clone https://github.com/Rajudas94/Flappy-Bird-Clone.git<br>

- Navigate to the project directory:<br>
cd Flappy-Bird-Clone<br>

- Install the required dependencies:<br>
pip install pygame<br>

Usage:<br>
- Run the game using:  python flappy_bird.py

# Press SPACEBAR to make the bird flap.
# Avoid hitting the pipes for a bigger score.
